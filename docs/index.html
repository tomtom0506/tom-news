שמירה

הדבק את הטוקן ולחץ "שמור הגדרות". הטוקן משמש רק לשמירה הזו ולא נשמר בטלפון.

איך יוצרים טוקן (פעם אחת)
  1. פתח: https://github.com/settings/personal-access-tokens/new
  2. Token name: tom-news-settings. Expiration: Custom, עד שנה קדימה.
  3. Repository access: Only select repositories ← tom-news.
  4. Permissions ← Repository permissions ← Contents: Read and write. שום הרשאה אחרת.
  5. Generate token. שמור אותו במנהל הסיסמאות של הטלפון, לא בפתקים.
